👨‍💻 Personal Profile Website

A modern and responsive personal profile website built using HTML and Tailwind CSS.

📌 About The Project

This is my personal profile website where I showcase information about myself, my skills, and my development journey.

The website is designed with a modern UI, responsive layout, gradients, glassmorphism effects, and smooth hover/transition effects.
